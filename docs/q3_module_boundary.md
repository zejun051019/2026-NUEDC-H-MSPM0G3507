# 第 3 问模块边界与行为保护

## 目标

本目录中的代码负责钢球从中心到 `+5 cm`、再返回 `-5 cm`、保持并回到会话零点。
第 4 问不得改变这条静态运动链路的参数、状态转移或视觉协议。

## Q3 业务模块

| 模块 | 职责 | 第 4 问使用规则 |
| --- | --- | --- |
| `q3_sequence.c/.h` | 第 3 问运动状态机、返程参考目标、提前刹车、回零 | 只读状态接口，不修改状态机 |
| `ball_position_control.c/.h` | 视觉位置更新、估计速度、外环 PD、X42S 角度命令 | 只通过公开接口调用，不改 Q3 参数 |
| `ball_outer_pd.c/.h` | 摆杆角度域 PD、限幅、斜坡和静摩擦起步补偿 | 第 4 问不得复用内部静态变量 |
| `ball_state_estimator.c/.h` | 视觉位置/速度估计和异常帧门控 | 第 4 问如需底盘速度估计，应建立独立模块 |
| `pendulum_geometry.c/.h` | 电机角度与摆杆角度/高度映射 | 保持 Q3 标定关系不变 |
| `q3_control_config.h` | Q3 机械、时序和返程参数 | 第 4 问禁止直接编辑 |
| `ball_control_config.h` | Q3 外环增益、限幅和起步参数 | 第 4 问禁止直接编辑 |

## 第 4 问允许新增的边界

建议新增：

```text
user/app/q4/
  chassis_speed_control.c/.h
  line_tracking.c/.h
  q4_sequence.c/.h
  q4_control_config.h
```

第 4 问通过 `Q3Sequence_IsActive()`、`BallPositionControl_GetStatus()` 等公开接口读取
钢球状态；底盘控制只产生速度/加速度扰动，不直接改写 `target_cm`、PD 增益或 Q3 状态。

## 调度约束

主循环仍保持：视觉接收 → 执行器反馈 → Q3 控制 → Q3 状态机 → 日志。
第 4 问任务应作为独立任务插入，不改变 Q3 控制调用顺序和视觉中断。

## 行为保护边界

后续问题集成不得改变 Q3 的控制参数、标定、状态转移或运行时序。代码格式、命名说明和文档可以统一整理；任何功能变更必须单独说明原因并通过相应回归和实机验证。此边界保护的是运行行为，不要求 Q3 源码字节保持不变。
